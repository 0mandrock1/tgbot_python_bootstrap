# Telegram-бот без програмування

Готовий шаблон Telegram-бота. Увесь бот налаштовується одним файлом —
`bot_config.py`. Відкривати теку `engine/` не потрібно.

З коробки бот уміє:
- Відповідати на команди (`/start`, `/help`, `/id`, і свої власні з конфіга).
- Показувати клавіатуру з кнопками та реагувати на ключові слова в чаті.

## Швидкий старт

1. **Отримай токен.** У Telegram відкрий [@BotFather](https://t.me/BotFather),
   напиши `/newbot`, дай боту ім'я — отримаєш токен (рядок типу
   `123456789:AAAa-BBBcccDDDeee...`).
2. **Завантаж код.** Натисни зелену кнопку `Code` → `Download ZIP` на цьому
   репозиторії (або `Use this template`) і розпакуй архів.
3. **Встав токен.** У теці з ботом знайди файл `.env.example`, зроби його
   копію з назвою `.env` і встав туди свій токен після `BOT_TOKEN=`.
4. **Запусти.**
   - Windows: двічі клікни на `start.bat`.
   - macOS/Linux: відкрий термінал у теці з ботом і виконай `sh start.sh`.
5. Напиши своєму боту в Telegram `/start`.

### Як відкрити термінал, якщо раніше не доводилось

- **Windows**: у теці з ботом, затиснувши Shift, клікни правою кнопкою миші
  на вільному місці → "Открыть окно PowerShell здесь" (або просто двічі
  клікни `start.bat` — термінал не потрібен).
- **macOS**: відкрий Finder → перейди в теку з ботом → правою кнопкою на
  теці → "Services" → "New Terminal at Folder" (або Spotlight → "Terminal").
- **Linux**: у файловому менеджері — правою кнопкою на теці → "Open in
  Terminal".

### Якщо немає Python

Завантаж і встанови з [python.org/downloads](https://www.python.org/downloads/).
На Windows під час встановлення обов'язково позначай "Add python.exe to PATH".

## «Хочу X → міняю Y»

| Хочу... | Редагую секцію в `bot_config.py` |
|---|---|
| Змінити привітання бота | `texts.start` |
| Змінити текст довідки | `texts.help` |
| Додати нову команду | `commands` |
| Додати кнопку | `buttons` |
| Бот реагував на слово в чаті | `keywords` |
| Отримувати сповіщення при старті бота | `adminIds` + `notifyAdminsOnStart` |

## Рецепти

Після кожної зміни — **збережи файл і перезапусти бота**.

### Нова команда

```python
commands = [
    {
        "command": "weather",
        "description": "Показати погоду",
        "reply": "Сьогодні сонячно ☀️",
    },
]
```

### Кнопка

```python
buttons = [
    [
        {"text": "☀️ Погода", "reply": "Сьогодні сонячно ☀️"},
    ],
]
```

### Реакція на слово

```python
keywords = [
    {"words": ["погода"], "reply": "Хочеш дізнатись погоду? Напиши /weather"},
]
```

### Відповідь з картинкою

```python
commands = [
    {
        "command": "cat",
        "description": "Фото котика",
        "reply": {
            "text": "Ось котик!",
            "photo": "https://placekitten.com/400/300",
        },
    },
]
```

### Кнопка-посилання

```python
commands = [
    {
        "command": "site",
        "description": "Наш сайт",
        "reply": {
            "text": "Переходь за посиланням:",
            "links": [{"text": "Відкрити сайт", "url": "https://example.com"}],
        },
    },
]
```

## Щось зламалось

| Симптом | Причина | Що зробити |
|---|---|---|
| "Не знайдено файл .env" | Забув створити `.env` з `.env.example` | Скопіюй `.env.example` → `.env`, встав токен |
| "Токен у .env виглядає неправильно" | Токен не схожий на справжній | Візьми точний токен у @BotFather без пробілів |
| "Токен невірний" | Неправильний або відкликаний токен | Отримай новий токен у @BotFather |
| "Бот уже запущений деінде" | Бот уже працює в іншому вікні/комп'ютері | Закрий іншу копію бота |
| "Помилка конфігурації: ..." | Помилка в `bot_config.py` | Повідомлення називає секцію й значення — виправ саме його |
| Бот не відповідає | Процес не запущений або впав | Запусти `start.sh` / `start.bat` знову, перевір повідомлення в терміналі |
| Змінив конфіг, а нічого не змінилось | Бот не перезапущено | Закрий бота (Ctrl+C) і запусти знову |

## Щоб бот працював 24/7

Поки на твоєму комп'ютері запущено `start.sh`/`start.bat`, бот працює. Вимкнув
комп'ютер — вимкнувся бот. Щоб бот жив постійно, його треба тримати на
сервері:

- **Linux-сервер**: скопіюй `deploy/tgbot.service` у `/etc/systemd/system/`,
  виправ шляхи всередині й виконай `systemctl enable --now tgbot`.
- **Будь-яка ОС**: можна скористатись [pm2](https://pm2.keymetrics.io/)
  (`pm2 start bot.py --interpreter .venv/bin/python`).

## Виріс із конфіга

Коли можливостей `bot_config.py` стає замало — пиши власний код у `custom.py`
(всередині вже є два закомічені приклади). Це звичайний Python з
[aiogram](https://docs.aiogram.dev/) — бібліотекою, на якій працює рушій.

## Токен — це пароль

Не публікуй токен і не надсилай його нікому. Файл `.env` навмисно додано в
`.gitignore`, щоб він не потрапив у git. Якщо токен усе ж "засвітився" —
відклич його в @BotFather (`/mybots` → твій бот → "API Token" → "Revoke
current token") і отримай новий.
